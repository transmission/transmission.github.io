Highlights include:

  • Fixed a potential remote code execution vulnerability in the macOS client (requires local write access to preferences; not remotely exploitable).
  • Fixed a bug that prevented some magnet links from being added correctly.
  • Fixed a 4.1.0 regression that could cause torrents with zero-byte files to lose downloaded progress.
  • Migrated Sparkle update signing from DSA to EdDSA.
  • Various other bugfixes and security improvements.
